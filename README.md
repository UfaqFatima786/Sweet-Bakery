# 🧁 Sweet Bakery

A modern and visually appealing **bakery website** designed to showcase delicious baked treats through a clean, attractive, and responsive frontend experience.

**Sweet Bakery** focuses on creating a warm and inviting digital presence for a bakery, combining elegant design, appealing food imagery, and a user-friendly layout.

## 🍰 About The Project

Sweet Bakery is a frontend web project created to practice modern website design and responsive development.

The website presents a bakery-inspired interface with an attractive visual style, organized content, and a focus on creating a pleasant browsing experience for visitors.

The project demonstrates how HTML, CSS, Bootstrap, and JavaScript can be combined to build a polished and responsive business website.
