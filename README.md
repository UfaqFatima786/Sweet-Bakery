## 📖 About The Project

Sweet Bakery is a frontend web development project created to build a visually appealing online presence for a modern bakery.

The website focuses on presenting bakery products such as cakes, pastries, cupcakes, and other sweet treats through a clean and responsive design.

It demonstrates the use of **HTML, CSS, and JavaScript** to create a complete frontend website with an attractive layout, responsive sections, interactive elements, and a polished user experience.
